# SouMeter
- 部屋の温湿度の7セグメントLEDによる数値表示およびクラウドアプリケーション(Ambient)によるグラフ表示を行うプロジェクト
- 名前の由来 そうめんの箱から作ったから（適当）

### 1.概要
- 温湿度センサーから室内の 温度 と 湿度 を取得
- 7セグメント LED 表示器で温湿度を表示
- インターネットを通じて温湿度データを送信／公開（WiFi 等を使用）
- ローカル（LED表示）と遠隔（ネット経由）両方でのモニタリングを可能にする

### 2.ソースコード構成
| ファイル                  | 内容                        |
| --------------------- | ------------------------- |
| `SouMeter_public.ino` | Arduinoスケッチのメイン関数         |
| `sevensegLED.h`       | 7セグメントLED制御関数をまとめたヘッダファイル |
| `sevensegLED.cpp`     | 7セグメントLED制御関数をまとめたソースファイル |

- 外部使用ライブラリ
  - WiFi.h
  - Ambient.h
  - DHT.h

### 3.ハード・ソフト構成
| 種別      | 部品名                            | 数       | 備考           |
| ------- | ------------------------------ | ------- | ------------ |
| マイコン    | ESP32 Dev Module               | 1       | 制御用          |
| センサー    | DHT22                          | 1       | 温湿度センサ       |
| シフトレジスタ | 74HC595                        | 3       | 7セグメントLED駆動用 |
| 表示器     | OSL40391-IB                    | 2       | 温度・湿度表示用     |
| 抵抗      | 330Ω                           | 各セグメント分 | 電流制限用        |
| 配線      | ジャンパ線                          | 必要数     | ブレッドボード等     |
| ソフト     | Arduino IDE                    | 1       | 書き込み用        |
| サービス    | [Ambient](https://ambidata.io) | -       | クラウド可視化      |


### 4.動作方法
#### (1) リポジトリをクローン
```bash
git clone https://github.com/kabosuxu/SouMeter.git
cd SouMeter
```

#### (2) 必要ライブラリをインストール & 外部利用サービス登録
- WiFi.h , Ambient.h , DHT.h のインストール
- [Ambient](https://ambidata.io) のユーザ登録(無料) & チャネル作成

#### (3) SouMeter_public.ino の編集
- L09 : 接続先インターネットルータのSSID記入
- L10 : 接続先インターネットルータのパスワード記入
- L16 : (2)で作成したAmbientのチャネルを記入
- L17 : (2)で作成したAmbientのライトキーを記入

#### (4) マイコンの書き込み
- Arduino IDE または他の互換環境でプロジェクトを開く
- ボード種類とシリアルポートを選ぶ
- ビルド → アップロード

#### (5) 動作確認チェック
- LED 表示が正しく数値を示すか
- ネットワーク接続が成功しているか、データ送信が行えているか（Ambient の画面やシリアルログで確認）
- シリアルモニタを有効にして、エラーやデバッグメッセージを確認
